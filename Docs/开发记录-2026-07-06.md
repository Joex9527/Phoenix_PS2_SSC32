### 关键架构决策

- **纯 C 实现**：不引入 Arduino 依赖，使用 ESP-IDF 原生 API
- **配置分离**：`robot_config.h` (运动学) / `board.h` (硬件引脚) / `Servo_Cfg.h` (舵机映射)
- **统一控制接口**：`ControlState_t` 作为唯一数据交换结构 — PS2 写入、PhoenixLoop 读取
- **低耦合**：PS2/SerialProtocol 通过 `spi_device_handle_t` / `uart_port_t` 参数注入，不依赖 `main/`

## 3. 实现的模块

### 3.1 Body IK（旋转矩阵法）
- 旋转顺序：Yaw(Z) → Pitch(Y) → Roll(X)
- 逆旋转：Rᵀ = Rx⁻¹ ⋅ Ry⁻¹ ⋅ Rz⁻¹
- 6 腿安装偏移查找表

### 3.2 步态引擎
- 4 种步态框架：Tripod 6/8, Ripple 6/12
- 正弦曲线抬腿轨迹 + 直线落地推地
- `GaitIsLegLifted()` / `GaitGetLegPhase()` / `GaitGetLegPhaseOffset()`

### 3.3 PS2 驱动
- ESP-IDF `spi_master` API (SPI2_HOST, Mode 3, 250kHz)
- PS2 配置序列：short poll ×3 → enter config → analog mode + lock → exit config
- 9-byte 模拟模式轮询，按钮位掩码 (16-bit) + 4 摇杆轴
- 5 种控制模式完整映射：
  - **WALKMODE**: 左摇杆行走 / 右摇杆旋转
  - **TRANSLATEMODE** (L1): 身体平移
  - **ROTATEMODE** (L2): 身体旋转
  - **SINGLELEGMODE** (○): 单腿控制
  - **GPPLAYERMODE**: 预留

### 3.4 上位机串口协议
- LewanSoul/Lobot `0xFE 0xFE [len] [cmd] [payload] 0xFA` 帧格式
- 帧解析状态机：IDLE → FE1 → FE2 → LENGTH → PAYLOAD → END → DISPATCH
- 支持命令：0x10 (上电), 0x20 (读取角度), 0x21 (单舵机), 0x22 (18舵机批量), 0x56/0x57 (扭矩)
- 角度编码：deg×100 → int16，扩展为 18 舵机 (36 字节负载)
- 超时检测：3 秒无命令自动释放控制权

### 3.5 主循环整合
- FreeRTOS 任务 `phoenix_task`，以 `GaitSpeed` 周期运行
- 输入优先级：上位机协议 > PS2 手柄
- 上位机控制时绕过 Phoenix 运动学，直接写入舵机角度
- START 按钮切换舵机电源 (RobotOn/Off)
